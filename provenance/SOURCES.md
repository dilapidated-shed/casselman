# Source provenance

This repository distinguishes **catalogued** sources from **mirrored** sources.

- **catalogued**: canonical URL and authorship are recorded, but the original file is not copied here.
- **mirrored**: the source has explicit redistribution terms that permit a public copy; the upstream notice and source location must travel with it.
- **personal fetch**: a helper may retrieve a source into the gitignored `personal/` directory when the source permits personal copying but not republication.

An accessible web page is not, by itself, permission to republish its files.

## MetaPost historical distribution — mirrored selectively

Upstream mirror:
https://github.com/classic-tools/MetaPost

Original author: John D. Hobby; historical AT&T Bell Laboratories distribution.

The upstream `DISCLAIMER` expressly places the MetaPost system in the public domain and explicitly includes `doc/*` documentation among the package contents. The upstream `NOTICE` is retained as provenance even though the disclaimer grants broader public-domain reuse.

Selected example sources are mirrored under `vendor/metapost/` with exact upstream paths and blob identifiers recorded there.

## Sergey Slyusarev — Byrne MetaPost

- https://github.com/jemmybutton/byrne-latex
- https://github.com/jemmybutton/byrne-euclid

`byrne.mp` identifies itself as copyright Sergey Slyusarev and GPL version 3 or later. The `byrne-euclid` README says the book sources are CC-BY-SA 4.0 and the MetaPost library / initials generator are GPLv3-or-later.

These are not copied wholesale here; `scripts/fetch_upstreams.sh` clones the authoritative repositories into ignored `upstream/` directories so their Git history and notices remain intact.

## Jyh-Ming Lien — ACD2D

https://github.com/jmlien/acd2d

Approximate convex decomposition of 2-D polygons; can emit PostScript and is useful as a geometry-to-PostScript generator specimen. Upstream `LICENSE` is MIT, copyright Jyh-Ming Lien (2018). Retrieved as an intact upstream clone rather than copied piecemeal.

## Unlicensed / unclear-source rule

A repository or web directory with source code but no found license may still be useful to study from its canonical location. It must not be copied into `vendor/` merely because it is publicly readable. Add it to the catalog with a note saying what license search was performed and what remains unknown.
