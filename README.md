# casselman

A provenance-first corpus of mathematical drawing programs and source references, centered on readable PostScript/MetaPost geometry and extending to related drawing and machine-motion languages.

The name honors Bill Casselman's *Mathematical Illustrations* and his long-running work on programmable mathematical graphics. This repository is independent and is not affiliated with Bill Casselman or UBC.

## Rules

- Keep the original author, source URL, copyright notice, and license/permission information with every mirrored item.
- Mirror an original only when redistribution permission is explicit enough for a public repository.
- When permission is unclear or reproduction is restricted, keep a canonical link and description instead of copying the file.
- Never strip notices from upstream source.
- Keep local/personal-use downloads out of Git.
- Keep later Idriç translations and experiments visibly separate from historical originals.

The point is not to collect rendered pictures. The useful artifacts are programs in which geometry is inspectable: points, paths, curves, transformations, drawing state, composition, and—in related machine languages—physical motion.

See `provenance/`, `catalog/`, and `scripts/` for the source inventory and reproducible retrieval notes.

## Thanks
